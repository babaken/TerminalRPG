# FirstQuest 3・4章 プロット案

1・2章の伏線（錆びた剣／主人公だけが狙われる／冒険者の死亡増加／モグラが持っていた地図／見張りのいるダンジョン）を回収する前提で3案を用意した。

---

## 案A 「封印の剣」— 王道型

**核心:** 錆びた剣は魔王の配下を封じた「封剣」。封印が弱まり、剣を持つ者を消そうとモンスターが主人公を狙っている。冒険者の死はダンジョン最深部で進む封印解除の儀式の生贄集め。

**3章（転）**
- 調査へ: B12F以降へ。冒険者の遺品と儀式の痕跡を発見。
- 挫折: 最深部で幹部「灰のガルザ」と遭遇（負けイベント）。剣が反応せず完敗、仲間1人が重傷。協会に担ぎ込まれる。
- 強化開始: 協会長から剣の由来を聞く。古い神殿で試練（職業ごとのソロ試練）→ 剣の錆が半分落ちる。各仲間の上位スキル習得。
- 最強の敵の話: 神殿の司祭が語る、かつて剣を封じた勇者と「三柱の魔」の伝承。

**4章（結）**
- ボスの名: ガルザが仕える「蝕王ヴェルム」— 三柱の魔のひとつ。
- ボス戦: ガルザ戦 → 儀式で半覚醒したヴェルム戦（2段階、剣が完全に光る演出 flash＋starfall）。
- 第2第3の敵: 倒れたヴェルムが「残る二柱はすでに目覚めている」と言い残す。
- 帰還: 協会で報告。追放された村から使者が来て和解、ただし主人公は旅を続けることを選ぶ。

**向き:** 分かりやすさ重視、サンプルとして最も標準的。

---

## 案B 「協会の裏切り」— サスペンス型

**核心:** 冒険者の死は冒険者協会の幹部が仕組んだもの。幹部は魔物と取引し、強い冒険者を危険な依頼に送り込んで消している。錆びた剣は魔物側にとって「契約を破る力」があり、だから主人公が狙われた。

**3章（転）**
- 調査へ: 指名依頼の報告書に不審点。失敗した依頼の依頼主がすべて同じ偽名。
- 挫折: 真相に近づいた矢先、協会から「村襲撃の犯人」として手配される（1章の村人の不信が利用される）。街を追われ、装備も没収。
- 強化開始: 地下の闇市場・他国の小さな協会支部で再起。無名の依頼をこなしながら証拠集め。遊び人の人脈・テイマーの魔物の嗅覚が活きる。
- 最強の敵の話: 取引相手の魔物「仮面の伯爵」の存在を知る。

**4章（結）**
- ボスの名: 副協会長エドモンド＝仮面の伯爵本人（人に化けた魔物）。
- ボス戦: 協会本部で正体を暴く（証拠アイテムの有無で会話分岐）→ 本性を現して戦闘。
- 第2第3の敵: 伯爵の懐から「他国の協会」「王宮」宛ての契約書が見つかる。
- 帰還: 汚名が晴れ、協会から正式に称号を授与。

**向き:** 会話・分岐・フラグ機能のショーケースになる。戦闘より物語重視。

---

## 案C 「主人公の正体」— どんでん返し型

**核心:** 主人公自身が、かつて魔物の王が「器」として人里に隠した子。錆びた剣は器を目覚めさせる鍵で、魔物は主人公を「迎えに来ていた」。殺すためではなく連れ戻すため。

**3章（転）**
- 調査へ: ダンジョン最深部の壁画に、主人公とそっくりの子供と錆びた剣が描かれている。
- 挫折: 魔物の将「ネイヴ」が主人公にだけ跪き、仲間の前で「お帰りなさいませ」と告げる。パーティ内に不信が走り、1人が離脱（2章で加入したメンバーから選択可）。
- 強化開始: 実家へ戻り、家族から「森で拾った子だった」と告白される（1章の家族団らんが効いてくる）。それでも家族だと受け入れられ、離脱した仲間も戻る。
- 最強の敵の話: 魔物の王は器を取り込んで完全体になろうとしている。

**4章（結）**
- ボスの名: 「虚ろの王ゼノ」。
- ボス戦: ゼノが主人公の体を乗っ取ろうとする → 精神世界での単独戦（tint で色調反転）→ 仲間の呼びかけで帰還し、パーティ全員で最終戦。
- 第2第3の敵: ゼノは「器はお前だけではない」と言い残す。他の器を探す勢力の存在。
- 帰還: 村へ帰ると、追い出した村人たちが謝罪。主人公は剣を背に再び旅立つ。

**向き:** 1章の家族・村八分が最も効く。感情の起伏が大きく、エフェクトの見せ場も多い。
