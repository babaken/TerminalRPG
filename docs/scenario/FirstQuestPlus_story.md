# FirstQuest+ シナリオ本文（テキスト版） v0.1

- 位置づけ: 追加シナリオ。案C「主人公の正体」をベースにする。v1.0.0 のあとに実装する（開発計画 M8）。
- パッケージ ID（予定）: `firstquest_plus`（FirstQuest とはセーブ非互換の別パッケージ）
- 構成: 1・2章は FirstQuest（`FirstQuest_story.md`）と共通の骨格に **伏線の差分** を加える。3・4章は全面的に差し替える。
- 表記は FirstQuest_story.md と同じ。

## 0. コンセプト

### 0.1 核心
{hero}は、15年前に魔物の王「虚ろの王ゼノ」が人里に隠した「器」だった。
ゼノは三百年前の戦いで肉体を失い、自分を宿す新しい体として赤子を作り、人の村に紛れ込ませた。
錆びた剣「鍵の剣」は、器を目覚めさせる鍵である。
魔物が{hero}だけを狙っていたのは、殺すためではない。**連れ戻すため**だった。

### 0.2 FirstQuest（案A）との違い
| 項目 | FirstQuest | FirstQuest+ |
|---|---|---|
| 剣 | 封剣アストラ（魔を封じる剣） | 鍵の剣（器を目覚めさせる剣）→ 最後に「{hero}自身の剣」に変わる |
| 魔物が主人公を狙う理由 | 剣の持ち主を消すため | 器を迎えに来たため |
| 冒険者の失踪 | 封印を解く儀式の贄 | 器の代わりを作る実験台（失敗作が魔物化） |
| 3章の挫折 | 幹部に完敗、仲間が重傷 | 正体が明かされ、仲間 1 人が離脱 |
| 家族 | 送り出す役 | 「拾った子だった」と告白し、それでも家族だと受け入れる |
| ボス | 蝕王ヴェルム | 虚ろの王ゼノ（精神世界の単独戦→パーティ戦） |
| 次回作への引き | 残る二柱の魔 | 「器はお前だけではない」――他の器を探す勢力 |

### 0.3 追加人物
| 人物 | 役割 |
|---|---|
| 魔将ネイヴ | ゼノの側近。器を迎えに来る。主人公にだけ礼を尽くす。紳士的で冷たい |
| 研究者グレイ | 冒険者協会の元研究員。ゼノ側に寝返り、失踪事件の実行役（2・3章） |
| 老婆テラ | リト村の外れに住む薬師。15年前、赤子の{hero}を森で見つけた人物（1章・3章） |
