# FirstQuest シナリオ本文（テキスト版） v0.1

- 位置づけ: `scenario.sco` 作成の元になるテキスト。会話・演出・分岐・データ要件を記す。
- 3・4章プロット: 案A「封印の剣」
- 表記
  - `【場面 ID】場所（マップ ID）` … シーン見出し。ID はそのまま `*ラベル` 名にする
  - `▶演出:` … エフェクト・画面処理（`@effect` 等）
  - `▶戦闘:` … `@battle` 指定
  - `▶フラグ:` / `▶入手:` / `▶加入:` … 状態変化
  - `{hero}` … 主人公名（既定「ユウ」、ニューゲーム時に入力）

> - 風見の神殿へは、洞穴前の東の落石（騎士団がどける）から風見の山道（`field_mountain`、雪。雪狼・氷の精）を登る。

> - 三つの試練のあと司祭オルドに話すと、倒れていた仲間が戻り、全員が職業ごとの上位スキル（旋風斬・フレイムストーム・ハイヒール・ジャックポット・猛攻・群れの咆哮）を覚え、三柱の魔の伝説 → 第3章 完。
